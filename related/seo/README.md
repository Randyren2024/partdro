# SEO Strategy

## Overview

SEO module for Partdro / Vesper AgriTech website -- driving organic traffic from target markets (Africa, India, Latam, Southeast Asia) searching for agricultural drones, firefighting drones, thermal inspection drones, and robotics solutions.

## Target Keywords

### Core Product Keywords
- agricultural drone, farming drone, crop spraying drone
- cargo drone, delivery drone, logistics drone
- firefighting drone, fire inspection drone
- thermal drone, thermal inspection UAV
- industrial robot, robotic arm, automation solution

### Long-tail / Geographic Keywords
- drone supplier in China, drone manufacturer China
- agricultural drone price, cargo drone cost
- drone for firefighting in [region], agricultural UAV in [country]

## Content Strategy

| Content Type | Purpose | Target |
|-------------|---------|--------|
| Product Pages | Showcase specifications and pricing | Bottom-funnel buyers |
| Blog / Case Studies | Demonstrate real-world applications | Mid-funnel consideration |
| Industry Guides | Establish thought leadership | Top-funnel awareness |
| Comparison Pages | Help buyers decide (vs competitors) | Bottom-funnel |

## On-Page SEO Checklist

- [ ] Custom <title> + <meta description> per page
- [ ] H1 + semantic heading hierarchy (H2, H3)
- [ ] Image alt text with keywords
- [ ] Structured data (Organization, Product, BreadcrumbList, FAQ)
- [ ] URL slugs: descriptive, hyphens, no IDs
- [ ] Internal linking between related product pages

## Technical SEO

- [ ] XML Sitemap submitted to Google Search Console
- [ ] robots.txt properly configured
- [ ] Core Web Vitals passing (LCP < 2.5s, FID < 100ms, CLS < 0.1)
- [ ] Mobile-friendly responsive design
- [ ] HTTPS enforced (Netlify default)
- [ ] Canonical URLs to prevent duplicate content
